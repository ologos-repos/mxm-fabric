# Requirements

Two requirement families live here:

- [EAF-requirements.md](EAF-requirements.md): EAF-001 to EAF-020, the
  Epistemic Assurance Framework requirements, traced from
  SPEC-MXM-EAF-0001 §10.
- [REQ-MXK-VER.md](REQ-MXK-VER.md): REQ-MXK-VER-01 to 05, the
  verification-boundary requirements (source WP-MXK-0008, implemented
  by WP-MXK-0009, decided in ADR-MXK-0006).

Kernel behavior requirements are carried by the enforcement
specification itself (`05-mxm-construct/means/enforcement/SPEC.md`)
and traced to tests in that folder's TRACEABILITY.md, rather than
restated here. The cross-baseline traceability spine
(WP-MXK-0015 step 5) records that path explicitly.
