# WP-MXK-0001 — Stand up the MxM kernel repository

Turns this repository into the kernel's real home:
- a self-hosted process home with a protected main line;
- required CI on every change;
- an automatic mirror;

  offline-verified copy.

This package's own pull request is the first proof that the gate works.
