# WP-MXK-0007 — Signed principal records and closed act outcomes

The follow-up independent review found the earlier holes closed and raised narrower issues
about bookkeeping. The log could show Operator or Advisor activity that was never signed, and
it could lose track of what actually happened when a tool ran but its receipt could not be
written.

Now every Operator or Advisor entry is signed. Every action that does something ends with
exactly one entry saying whether it was done, failed, was skipped, or has an unknown result.
