# Memory

Canonical continuity lives in [MEMORY.md](../../MEMORY.md) and
[memory/](../memory). The principal binding lives in [profile.json](profile.json).
`MEMORY.md` is a short index and current focus, not a transcript archive.
Read relevant records at session start and before relying on past decisions.
Native harness histories are session records; they do not silently override
validated durable facts.

Record user-confirmed facts and decisions with source, date, scope and any
supersession or defeater. Keep model inferences explicitly marked as candidates.
The `remember` command creates candidate JSON notes only; it never promotes
its own output to accepted fact. Review relevant candidate notes with the
principal, then record validated conclusions in `MEMORY.md` with attribution.
Keep original candidate evidence. No automatic candidate harvesting is installed.

Flush meaningful decisions, progress, remaining work and corrections before a
context boundary. Update the index and relevant work record, then commit only
reviewed files. Ask before publishing personal memory unless already authorized.
Do not retain secrets or unnecessary sensitive details. Notes here can be read
by the repository owner and collaborators. Local scratch goes in ignored `06-operations/local/`;
it has no backup or automatic continuity guarantee.

## Companion rationale
