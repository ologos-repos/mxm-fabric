# Recovery

Restore a clean checkout using your own authorized Git account. Reinstall Git,
Python and your chosen agent harness as needed; authenticate with your own
accounts. Run the layout checker and session-start tool, then read MEMORY.md
and the active focus. Restore no credentials from this repository.

A committed note survives a checkout restore; ignored local scratch does not.
Remote publication is a separate action: verify the intended commit was pushed
before assuming another machine can recover it.
